# Movie Recommendation System

A content-based movie recommendation system that suggests movies similar to a user’s favorite movie.

## Objective
To recommend movies using content similarity techniques.

## Techniques Used
- TF-IDF Vectorization
- Cosine Similarity
- difflib for string matching

## Outcome
The system successfully recommends relevant movies based on user input.

## Tools & Technologies Used
- Python
- Jupyter Notebook
- Pandas
- NumPy
- Scikit-learn
